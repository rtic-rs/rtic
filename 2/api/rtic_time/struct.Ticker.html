Struct Ticker 

Source 
pub struct Ticker<T: Timebase> { /* private fields */ }
Expand description

Yields ticks at a fixed period.

Tick n is scheduled at start + n * period, so wake-up latency does not add up over time.

If ticks are missed, the following calls to tick complete at once until the schedule is caught up. Use reset to drop the missed ticks instead.

On a wrapping timebase the ticker must not fall behind by more than half the counter range, as a missed tick then looks like a tick in the future.

ⓘ
let mut ticker = Mono::ticker(1.secs());
loop {
    let at = ticker.tick().await;
}
