Struct Instant 

Source 
pub struct Instant<T, const NOM: u64, const DENOM: u64, K> { /* private fields */ }
Expand description

Represents an instant in time.

The generic T can either be u32 or u64, and the const generics represent the ratio of the ticks contained within the instant: instant in seconds = NOM / DENOM * ticks

K says how the timeline is read. See kind, or use an alias such as WrappingInstant.

Adding or subtracting a Duration in a different time base is subject to the same base ratio limits as Duration itself: bases differing by more than T::MAX are a compile-time error rather than a silent truncation.

pub const fn const_partial_cmp(self, other: Self) -> Option<Ordering>

Const partial comparison of Instants.

let i1 = WrappingInstant::<u32, 1, 1_000>::from_ticks(1);
let i2 = WrappingInstant::<u32, 1, 1_000>::from_ticks(2);

assert_eq!(i1.const_partial_cmp(i2), Some(core::cmp::Ordering::Less));

This function takes into account that ticks might wrap around: self - other is read as a signed offset, so an Instant just past the wrap point comes after one just before it:

let i1 = WrappingInstant::<u32, 1, 1_000>::from_ticks(u32::MAX);
let i2 = WrappingInstant::<u32, 1, 1_000>::from_ticks(1);

assert_eq!(i1.const_partial_cmp(i2), Some(core::cmp::Ordering::Less));

Returns None when the two are exactly half the tick range apart. There self - other and other - self are the same value, so neither can be said to come first:

let i1 = WrappingInstant::<u32, 1, 1_000>::from_ticks(0);
let i2 = WrappingInstant::<u32, 1, 1_000>::from_ticks(1 << (u32::BITS - 1));

assert_eq!(i1.const_partial_cmp(i2), None);

pub const fn is_before(self, other: Self) -> bool

Whether this Instant comes before other.

Wrap-aware, like const_partial_cmp, and usable in const contexts. Instants exactly half the tick range apart are incomparable, so this and is_after are both false for them.

    = WrappingInstant::<u32, 1, 1_000>::from_ticks(1);
const BEFORE: bool = I1.is_before(I2);

assert!(BEFORE);

pub const fn convert_sub_duration<const O_NOM: u64, const O_DENOM: u64>( self, other: Duration<u32, O_NOM, O_DENOM>, ) -> Option<Self>

Try to convert other into the Self::NOM / Self::DENOM timebase, and subtract it from this Instant.

Returns None only if the time-base conversion fails. The subtraction itself is wrapping, as Instants are circular.

The implementations of core::ops::Sub and core::ops::SubAssign are implemented by unwrap-ing the value returned by this function.

let i = WrappingInstant::<u32, 1, 1_000>::from_ticks(1);
let d = Duration::<u32, 1, 1_000>::from_ticks(1);

assert_eq!(i.convert_sub_duration(d).unwrap().as_ticks(), 0);

The subtraction itself is wrapping:

let i = WrappingInstant::<u32, 1, 1_000>::from_ticks(1);
let d = Duration::<u32, 1, 1_000>::from_ticks(2);

assert_eq!(i.convert_sub_duration(d).unwrap().as_ticks(), u32::MAX);

Overflow during Duration base conversion returns None:

let i = WrappingInstant::<u32, 1, 1_000>::from_ticks(1);
// A duration whose conversion from the `1/500` base to the `1/1000` base
// will overflow.
let d = Duration::<u32, 1, 500>::from_ticks(u32::MAX / 2 + 1);

assert_eq!(i.convert_sub_duration(d), None);
